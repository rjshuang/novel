## 简介
小说网文下载

## 使用方法
点击[Release](https://github.com/rjshuang/novel/releases)下载二进制包, 解压后运行

## 说明
1. 程序执行流程: 书源选择 -> 搜索 -> 书籍选择 -> 获取章节 -> 章节选择 -> 下载
2. 下载格式支持txt和epub
4. 内置四个免登录书源, 可根据规则扩展
5. 顶点小说有限流, 有封ip风险, 需设置代理池使用; 
   该站点搜索会跳转至第三方搜索, 需区分书籍设置search uri(e.g. /read/13281)
6. 章节选择为全本时, 开始章节和结束章节均输入-1即可
